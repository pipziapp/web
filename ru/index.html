Бесплатный тест скорости чтения

Узнай, сколько слов в минуту ты читаешь и насколько хорошо понимаешь текст, — примерно за 2 минуты, прямо в браузере.

Пройти тест
  • Начни с короткого замера (около 2 минут) и узнай свою стартовую скорость.
  • Иди по ежедневному пути из коротких уроков в твоём темпе.
  • Выполняй упражнения для скорочтения, вдохновлённые исследованиями чтения: пейсер для концентрации, беглый просмотр и поиск, предпросмотр, работа со словарным запасом.
  • После каждого текста отвечай на несколько вопросов — так скорость и понимание текста растут вместе.
  • Темп подстраивается после каждого урока: быстрее, когда ты хорошо понимаешь, мягче, когда трудно.
  • Каждую неделю новый замер скорости чтения показывает твой рост.
  • Сотни оригинальных текстов для любого уровня
  • Классика из общественного достояния на твоём языке
